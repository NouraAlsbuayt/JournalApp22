
# Journali

Journali is a professional journaling app that delivers a reliable writing and organization experience within a refined, carefully designed interface. It lets you easily create, edit, and delete entries, with automatic date saving and a clear warning if you attempt to close without saving changes. It supports instant search across titles and content, and allows adding bookmarks to highlight important entries for quick access.

## Features

- Create and edit journals with instant saving of changes.
- Instant search across titles and content.
- Bookmark each entry with quick toggling.
- Smart filtering by date or bookmarks.
